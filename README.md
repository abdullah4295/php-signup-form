# PHP Signup Form with MySQL (PDO)

A beginner-friendly PHP Sign Up form that saves to a MySQL database using PDO prepared statements.

## Features
- Input validation (`trim()`, name and city required checks)
- Secure database interaction using PDO & Prepared Statements (preventing SQL Injection)
- XSS prevention using `htmlspecialchars()`
- Live AJAX submission with `fetch()` and `FormData`
- Dynamic table rendering displaying registered users
